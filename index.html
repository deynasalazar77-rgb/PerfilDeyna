HABILIDADES

HTML

HTML (HyperText Markup Language) es el lenguaje que se utiliza para crear la estructura de una página web. Permite organizar títulos, párrafos, imágenes, tablas, formularios y enlaces.

CSS

CSS (Cascading Style Sheets) permite dar diseño a las páginas web, agregando colores, fuentes, animaciones, márgenes, posiciones y haciendo que el sitio sea responsive.

JAVA

JavaScript añade interactividad a una página web. Permite crear botones dinámicos, validar formularios, modificar el contenido y responder a las acciones del usuario.

GitHub

GitHub es una plataforma para almacenar proyectos, controlar versiones con Git y colaborar con otros desarrolladores de manera organizada.
